# Code of Conduct

## Our standard

This is a project built around helping people get healthier. Everyone who contributes, asks questions, or opens issues deserves to be treated with respect. Full stop.

We expect participants to:

- Be respectful and constructive in all interactions
- Assume good intent before assuming malice
- Accept feedback gracefully and give it kindly
- Focus on the problem, not the person

We will not tolerate:

- Harassment, discrimination, or personal attacks of any kind
- Dismissive or condescending language
- Spam or self-promotional behaviour unrelated to the project

## Enforcement

If you witness or experience behaviour that violates this code, please open a private GitHub issue or contact the maintainer directly. All reports will be handled with discretion.

Violations may result in comments being removed, contributions being rejected, or participants being blocked from the repository.

## Scope

This code of conduct applies to all project spaces: GitHub Issues, Pull Requests, Discussions, and any other venue where this project is represented.
